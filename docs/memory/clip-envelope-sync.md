Подія несе весь конверт одного параметра сходинками [[час, значення]] у СИРИХ одиницях. Читання -- value_at_time по сітці 1/8 долі з семплюванням СЕРЕДИНИ інтервалу; events_in_range для значень не годиться (віддає відображувані одиниці, при клампі inf). Запис -- delete_events_in_range + insert_step по сходинках. Конверт не має listener-а, тож зміни ловляться опитуванням: один кліп за прохід, не частіше разу на секунду, стеля ENVELOPE_PARAMS_PER_POLL. Круговий тест на живому 12.3.5 пройдено 4/4: намалював -> подія -> стер -> подав назад -> значення збіглися. У знімок подія поки НЕ входить -- дзеркала на JS не оновлені, і додавати її туди без них означало б рахувати пропущене застосованим.

**Чому:** Дві вади знайшлись лише живим прогоном і обидві тихі: абсолютний індекс замість ordinal серед однойменних (подія не резолвилась навіть у того, хто її випустив) і семплювання на межі інтервалу (фантомна перша сходинка зі старим значенням). Обидві прикриті тестами в bridge-lint.
