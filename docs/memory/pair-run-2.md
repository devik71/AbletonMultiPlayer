Прогін 29-30 серпня 2026, сесія jam4, Windows 12.3.5 + жива друга машина партнера. Знайдено чотири речі. ЗАКРИТО: переміщення кліпа давало партнеру два кліпи (див. [[listener-rewire-hazard]]); параметри всередині раків не доїжджали (див. [[chain-identity-address]]). МЕЖІ, не баги: formants і envelope Live у LOM не публікує взагалі (43 скаляри кліпа, 18 параметрів Simpler -- жодного), метроном не синхронізуємо свідомо як особисту річ, для спільної долі -- Ableton Link. ВІДКРИТЕ: вміст раку (кит, пресет) не переноситься нічим -- _device_is_bare мовчить для всього, що має власний вміст, тож завантаження з браузера не емітить події; на живому це виглядало як трек '6-505 Core Kit' з назвою, але без девайсів. Не всі набори warp-маркерів відтворювані через API -- див. docs/COVERAGE.md.

**Чому:** Перший прогін показував, що фундамент тримає. Другий уперше показав, ЩО САМЕ ламається в довгій живій грі, і дві з чотирьох знахідок виявились не багами, а межами Live -- їх треба знати, щоб не шукати виправлення там, де його не буде.
