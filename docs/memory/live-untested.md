Станом на 2026-08-26 із реальним bridge не перевірялись: relay-hardening (стиснення хвоста, холодний архів, евікція сесій), виправлення груп (b6c854c), Arrangement A і B для MIDI, ClipPropSet, ClipWarpSet, локатори, петля Arrangement, ReturnCreate/Delete, crossfade_assign, подвійна адресація кліпів. Через tools/pair-probe.mjs (живий Live як p1 плюс fake-live як p2) перевірено вісім речей: присутність, follow із реальним рухом виду, обмін знімками, undo від імені партнера, diff без застосування, поіменна розбіжність можливостей, status і локи (редагують: p1 зʼявляється в партнера і сам зникає). Передача файлів перевірена наскрізно: файл із p2 реально зʼявився в теці проєкту p1. Це НЕ заміна прогону парою: емулятор не має справжніх LOM-listener-ів. Раніше на живому: SampleLoad, SongPropSet, SceneTimingSet, структура девайсів.

**Чому:** Це головний ризик проєкту і причина суфікса -dev у версії. Він легко забувається, бо тести зелені.
