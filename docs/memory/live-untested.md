Після прогонів 27-28 серпня 2026 (Windows 12.3.5 + macOS 12.4.3) перевірено наживо в обидва боки, автоматично через tools/pair-live.mjs: темп, гучність, назви, присутність, локи, undo, кліп із нотами, треки, сцени, локатори, темп сцени, мікшер ланцюга в раку, стан девайса повз параметри (DeviceStateSet), маркери семплу (SamplePropSet), стоп-кнопка слота, кліп у лінійці, обмін знімками, diff. Плюс окремо: семпли байт у байт через межу файлових систем, скарга авторові про пропущену подію, Ableton Link. НЕ перевірено досі: групування треків (LOM не вміє створювати групи -- лише попередження), запис кліпа під час гри, DeviceLoad автоемісією, warp-маркери audio-кліпа (у тестовому сеті немає warped audio).

**Чому:** Перелік став коротким і конкретним. Три з чотирьох пунктів, що лишились, потребують рук у Live -- автоматизувати їх нічим.
