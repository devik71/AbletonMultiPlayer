Після прогонів 27-28 серпня 2026 (Windows 12.3.5 + macOS 12.4.3) tools/pair-live.mjs перевіряє автоматично двадцять речей в обидва боки: темп, гучність, назви, присутність, локи, undo, кліп із нотами, треки, сцени, локатори, темп сцени, мікшер ланцюга в раку, стан девайса повз параметри, маркери семплу, стоп-кнопка слота, кліп у лінійці, audio-семпл у слот, warp-маркери, знімки, diff. Окремо перевірено вручну: семпли байт у байт через межу файлових систем, apply_gap, Ableton Link, семпл на пад Drum Rack Windows -> macOS (28 серпня: OLIVER_kick лягла на пад 40 у партнера). НЕ перевірено досі: групування треків (LOM не вміє створювати групи), запис кліпа під час гри (потрібні руки й реальний вхід), DeviceLoad автоемісією (перетягування з браузера).

**Чому:** Лишились рівно ті три, які автоматизувати нічим або які впираються в межу LOM. Пад із списку вибув: він працює, коли браузер партнера бачить файл, а це вимога перезапуску Live після приїзду семпла -- див. docs/COVERAGE.md.
