27 серпня 2026 система вперше працювала на двох живих машинах через LAN: Windows (Live 12.3.5, p1) і macOS 12.4.3 Intel (p2, 192.168.3.18, користувач macbook, доступ по ключу SSH). Relay на Windows 192.168.3.24:19870, сесія jam3. Зелені в обидва боки: темп, гучність, назви треків, присутність, локи, undo, кліп із нотами, створення й видалення треку та сцени, обмін знімками, diff, передача семплів байт у байт через межу файлових систем. Журнал 65 подій, цілісність підтверджена. Інструмент прогону: tools/pair-live.mjs. Демон на обох боках читає команди з файлу через tail -f, інакше в нього нема як писати.

**Чому:** Це був головний гейт проєкту і причина суфікса -dev. Тепер він пройдений, але не для всього: див. live-untested і виміряні межі в COVERAGE.
